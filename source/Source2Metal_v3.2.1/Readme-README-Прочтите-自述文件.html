English

This version adds Polyglot BIN through BIN2PGN v0.1.3: complete legal BOOK RAW lines, separate outputs and merged CTG/BIN BOOK RAW with exact-line deduplication. BIN does not generate METAL. GAME-METAL and CTG-METAL remain separate. Read the manuals for the GAME Sources / BOOK Sources layout and filtering rules.

This is the portable Windows release of Source2Metal v3.2.0. No installation is required. Extract the ZIP and start !Source2Metal_v3.2.0.exe. The leading exclamation mark keeps the program near the top of a folder in Windows Explorer.

Source2Metal converts supported computer-chess sources and includes the published and practically validated SyzygyCheck v2.2.0 as the one unpackable utility. Choose main-menu option 2 > Extract separate SyzygyCheck package. Source2Metal writes SyzygyCheck_v2.2.0_UTILITY.zip. Unzip it; its executable is !SyzygyCheck_v2.2.0.exe, accompanied by 1_READ_FIRST_AL.txt, Docs_AL and Program_AL. Its verification core is based on the original Syzygy tablebase verification code by Ronald de Man.

SyzygyCheck can verify only the selected control folder or that folder and all real subfolders. It supports safe checkpoint/resume, full paths for FAIL and ERROR, thread selection, live effective read speed and a selectable result-report destination. It never changes tablebase files.

Source code is deliberately not duplicated inside the EXE or this user package. Beside Source2Metal_v3.2.0_RELEASE.zip, GitHub automatically provides Source code (zip) and Source code (tar.gz). No extra custom source ZIP is published because it would duplicate them. The EXE is unsigned, so Windows may show a warning; verify the user release and executable with the published SHA-256 file. Source2Metal and SyzygyCheck work locally and do not upload tablebase files, filenames or results.

Русский

Добавлена поддержка Polyglot BIN через BIN2PGN v0.1.3: полные легальные линии BOOK RAW, отдельные файлы и объединённый CTG/BIN BOOK RAW с удалением дубликатов полных линий. BIN не создаёт METAL. GAME-METAL и CTG-METAL остаются раздельными. Структура GAME Sources / BOOK Sources и правила фильтрации описаны в руководствах.

Это переносимая версия Source2Metal v3.2.0 для Windows. Установка не требуется. Распакуйте ZIP и запустите !Source2Metal_v3.2.0.exe. Восклицательный знак помещает программу ближе к началу списка файлов в Проводнике Windows.

Source2Metal преобразует поддерживаемые источники компьютерных шахмат и содержит опубликованную и практически проверенную SyzygyCheck v2.2.0 как единственную извлекаемую утилиту. Выберите пункт 2 главного меню > Извлечь отдельный пакет SyzygyCheck. Source2Metal создаст SyzygyCheck_v2.2.0_UTILITY.zip. Распакуйте его; внутри находятся !SyzygyCheck_v2.2.0.exe, 1_READ_FIRST_AL.txt, Docs_AL и Program_AL. Ядро проверки основано на оригинальном коде проверки таблиц Syzygy, созданном Ronald de Man.

SyzygyCheck может проверить только выбранную контрольную папку либо её вместе со всеми настоящими подпапками. Поддерживаются безопасное продолжение с контрольной точки, полные пути для FAIL и ERROR, выбор потоков, текущая эффективная скорость чтения и выбор места сохранения отчёта. Файлы таблиц программа не изменяет.

Исходный код намеренно не дублируется внутри EXE или пользовательского пакета. Помимо Source2Metal_v3.2.0_RELEASE.zip, GitHub автоматически предоставляет Source code (zip) и Source code (tar.gz). Дополнительный архив исходного кода не публикуется, так как он лишь дублировал бы их. EXE не подписан, поэтому Windows может показать предупреждение; проверьте пользовательский пакет и EXE по опубликованному SHA-256. Source2Metal и SyzygyCheck работают локально и не передают файлы таблиц, их имена или результаты проверки.

中文

本版通过 BIN2PGN v0.1.3 支持 Polyglot BIN，生成合法完整的 BOOK RAW 变例，并提供各源文件及按完整走子序列去重的合并 CTG/BIN BOOK RAW。BIN 不生成 METAL。GAME-METAL 与 CTG-METAL 仍保持独立。GAME Sources / BOOK Sources 目录和筛选规则详见手册。

这是 Source2Metal v3.2.0 的便携式 Windows 版本，无需安装。解压 ZIP 后运行 !Source2Metal_v3.2.0.exe。文件名前的感叹号可使程序在 Windows 文件资源管理器中靠前显示。

Source2Metal 可转换受支持的计算机国际象棋源文件，并内含经过实际验证的 SyzygyCheck v2.2.0 正式发布包，作为唯一可解出的实用工具。请选择 主菜单选项 2 > 解出独立 SyzygyCheck 包。Source2Metal 会写出 SyzygyCheck_v2.2.0_UTILITY.zip。解压后其中包含 !SyzygyCheck_v2.2.0.exe、1_READ_FIRST_AL.txt、 Docs_AL 和 Program_AL。 其验证核心基于 Ronald de Man 最初的 Syzygy tablebase 验证代码。

SyzygyCheck 可只检查所选控制文件夹，也可检查该文件夹及其所有真实子文件夹。 它支持安全的检查点续检、FAIL 和 ERROR 完整路径、线程选择、实时有效读取速度以及 结果报告保存位置选择，并且绝不会修改 tablebase 文件。

源代码不会在 EXE 或用户包内重复保存。除 Source2Metal_v3.2.0_RELEASE.zip 外，GitHub 还会自动提供 Source code (zip) 和 Source code (tar.gz)。 不会另外发布自定义源代码 ZIP，因为那只会造成重复。EXE 尚未签名，因此 Windows 可能显示警告；请使用已发布的 SHA-256 文件验证用户发布包和 EXE。Source2Metal 与 SyzygyCheck 均在本地运行，不会上传 tablebase 文件、文件名或检查结果。
