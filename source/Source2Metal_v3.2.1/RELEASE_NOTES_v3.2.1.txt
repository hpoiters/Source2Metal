Source2Metal v3.2.1 — ChessBase activity spinner (revision 3, 2026-09-21)

Normal filenames remain !Source2Metal_v3.2.1.exe and
Source2Metal_v3.2.1_RELEASE.zip. GitHub tag v3.2.1-r3 distinguishes this update
from the preserved v3.2.1 and v3.2.1-r2 releases.

The 2CBH/CBH progress line again has a rotating activity symbol before the
format name. It animates continuously even while a large individual game is
being decoded. The ordinary blinking terminal cursor is hidden only during
ChessBase conversion and restored on completion or error. Existing progress
bar, counts, percentage, ETA, completion display, output and decoder stay as
before. No change to the underlying 2CBH or CBH conversion algorithms.

All revision-2 functionality is preserved: the BIN2PGN display and adaptive
ETA, stable application-directory handling, BOOK RAW activity, all source
formats and output layouts. The SyzygyCheck utility stays unchanged v2.2.0.

The release is rebuilt from the complete Go source. Windows verification
compares PGN output of the approved kernel, rebuilt kernel and final launcher
in all seven languages, tests 49 language transitions, SyzygyCheck menu
extraction, working-directory isolation, source integrity and the packaged
release. Kernel differences are restricted to existing progress instrumentation
and the ChessBase progress-display adapter. Dedicated spinner layout tests
cover its four animation frames, console widths and unchanged progress text.

Publication as Latest follows passing all build and validation checks. All
earlier release tags, assets and metadata remain unchanged. The program is
unsigned.
