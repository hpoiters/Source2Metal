Source2Metal v3.2.1 — РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ (РУССКИЙ)
==========================================================

1. НАЗНАЧЕНИЕ
Source2Metal — переносимая программа Windows x64 для PGN, CBH, 2CBH, CTG и Polyglot BIN. PGN/CBH/2CBH создают GAME RAW и GAME-METAL. CTG и BIN создают BOOK RAW; CTG также имеет отдельную ветку METAL.

BIN2PGN 0.1.3: BIN создаёт только BOOK RAW; без BIN-METAL. Фильтры GAME по длине и Elo к BIN не применяются.

2. ЗАПУСК
Полностью распакуйте Source2Metal_v3.2.1_RELEASE.zip. Храните вместе EXE, краткое
введение HTML и папку Docs. Поместите !Source2Metal_v3.2.1.exe в папку с
исходными файлами; подпапки просматриваются автоматически. Установка не нужна.

Программа пропускает .git, TEMP, Tijdelijk, папки с окончанием _output и свою
папку !Source2Metal_Output. Источники только читаются, а результаты записываются
в новую папку с отметкой времени.

3. ПОЛНЫЕ НАБОРЫ ИСТОЧНИКОВ
- PGN: один файл .pgn.
- CTG: соответствующие файлы .ctg, .cto и .ctb.
- CBH: соответствующие файлы .cbh, .cbg, .cbp и .cbt.
- 2CBH: соответствующие файлы .2cbh, .2cbg и .2lid.
Неполные наборы отмечаются и не считаются полными без предупреждения.

- BIN: Polyglot .bin (16 bytes/record).

4. ГЛАВНОЕ МЕНЮ
1 = Обработать источники [по умолчанию]
2 = SyzygyCheck / файл подкачки
3 = Изменить язык
4 = Информация
0 = Выход

5. ПАРАМЕТРЫ ОБРАБОТКИ
Выберите рабочие потоки; по умолчанию половина доступных логических потоков CPU. Конвертация BIN и объединение BOOK выполняются последовательно.

Режим 1: только инвентаризация и отчёты.
Режим 2: отдельные и объединённые GAME RAW и BOOK RAW.
Режим 3 [по умолчанию]: режим 2 плюс существующие GAME-METAL и CTG-METAL.

Глубина RAW: 1–120 полуходов, по умолчанию 100. Минимум GAME: 1–120 полуходов, по умолчанию 24. Elo: 0 сохраняет отбор; 1 требует обоих >=2500; 2 обоих >=2400. Максимальная разница Elo: 0 без ограничения.

Устойчивость к ошибкам PGN: отдельная непригодная партия пропускается, а обработка этого источника продолжается. Обычные фильтры (Elo, длина, FEN/SetUp и дубликаты) ошибками не считаются. После чтения как минимум 100 партий, если 10% или более одного файла-источника непригодны, интерактивный режим один раз спрашивает, продолжать ли этот источник или остановить только его. Остальные файлы-источники и последующие этапы обработки продолжаются в обоих случаях. Неинтерактивные запуски автоматически продолжают обработку и записывают предупреждение. Структурная проверка RAW считает тег Result, который присутствует ровно один раз в каждой записанной записи GAME и BOOK, поэтому она не зависит от тега Event в исходном файле.

BIN2PGN 0.1.3: BIN создаёт только BOOK RAW; без BIN-METAL. Фильтры GAME по длине и Elo к BIN не применяются.

6. РЕЗУЛЬТАТЫ
Результаты записываются в:
  !Source2Metal_Output\ГГГГ-ММ-ДД_ЧЧ-ММ-СС\
Папка запуска содержит RAW и/или METAL и REPORTS. Результаты отдельных источников
и объединённые результаты остаются различимыми. Временные файлы адаптеров
удаляются в конце. Отчёты содержат настройки, источники, статус, сведения о
сборке и контрольные суммы SHA-256.

GAME-METAL содержит полные легальные исходные партии с исходным результатом и
использует статистику позиций/транспозиций. CTG-METAL использует книжные
свидетельства. Они разделены, поскольку смысл этих свидетельств различен.

Для Fritz «Обучение из базы» с Metal PGN: Победы ВКЛ, Поражения ВКЛ, Белые ВЫКЛ,
Чёрные ВЫКЛ, Игрок ВЫКЛ, имя игрока пустое, Партии ВСЕ.

BOOK RAW объединяет CTG и BIN. В объединённом BOOK-файле удаляются дубликаты полных легальных последовательностей ходов; префиксы и транспозиции остаются раздельными. При разных результатах или заголовках сохраняется первая запись (CTG перед BIN). Отдельные исходные файлы сохраняются. Результаты CTG получены из статистики книги; BIN использует *. Это не результаты сыгранных партий. ALL SOURCES RAW объединяет GAME RAW и объединённый BOOK RAW при наличии обоих, без межклассовой дедупликации. BIN не создаёт METAL.

RAW/1 - Separate Sources - RAW PGNs/GAME Sources/ (PGN, CBH, 2CBH)
RAW/1 - Separate Sources - RAW PGNs/BOOK Sources/ (CTG, BIN)
RAW/2 - Merged Sources - RAW PGNs/Source2Metal - Merged GAME Sources - RAW.pgn
RAW/2 - Merged Sources - RAW PGNs/Source2Metal - Merged BOOK Sources - RAW.pgn
RAW/2 - Merged Sources - RAW PGNs/Source2Metal - Merged ALL Sources - RAW.pgn

7. SyzygyCheck v2.2.0
Выберите пункт 2 главного меню, затем пункт 1. Source2Metal создаст рядом с EXE
файл SyzygyCheck_v2.2.0_UTILITY.zip. Полностью распакуйте его и прочтите

8. ИСХОДНЫЙ КОД, КОНФИДЕНЦИАЛЬНОСТЬ И ЦЕЛОСТНОСТЬ
Исходный код не встроен в EXE или Source2Metal_v3.2.1_RELEASE.zip. GitHub
автоматически предоставляет его как Source code (zip) и Source code (tar.gz).
Дополнительный пользовательский архив исходного кода не публикуется, поскольку
он только дублировал бы эти загрузки. Программы работают
локально и не отправляют источники, имена файлов tablebase или результаты.
Проверяйте загрузки по SHA256_Source2Metal_v3.2.1.txt. EXE пока не подписан,
поэтому Windows может показать «Неизвестный издатель» или SmartScreen.

Обновление консоли BIN2PGN (2026-09-16): видны счётчик файлов и время работы. Примерное общее оставшееся время появляется при достаточных данных, уточняется в ходе обработки и исчезает после BIN2PGN. Успешные предыдущие запуски сохраняются локально.
