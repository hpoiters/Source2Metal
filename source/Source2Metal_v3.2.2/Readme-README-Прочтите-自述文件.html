English

v3.2.2 fixes PGN batch resilience: an unusable game no longer aborts a long run, structural RAW verification no longer depends on a source Event tag, and at 10% unusable games in one source the interactive mode can stop only that source while all remaining files continue.

This version also includes Polyglot BIN through BIN2PGN v0.1.3: complete legal BOOK RAW lines, separate outputs and merged CTG/BIN BOOK RAW with exact-line deduplication. BIN does not generate METAL. GAME-METAL and CTG-METAL remain separate.

This is the portable Windows release of Source2Metal v3.2.2. No installation is required. Extract the ZIP and start !Source2Metal_v3.2.2.exe.

Source2Metal includes the published and practically validated SyzygyCheck v2.2.0 as the one unpackable utility. Choose main-menu option 2 > Extract separate SyzygyCheck package.

Source code is deliberately not duplicated inside the EXE or this user package. Beside Source2Metal_v3.2.2_RELEASE.zip, GitHub automatically provides Source code (zip) and Source code (tar.gz). The EXE is unsigned, so Windows may show a warning; verify the release with the published SHA-256 file.

Это переносимая версия Source2Metal v3.2.2 для Windows. Установка не требуется. Распакуйте ZIP и запустите !Source2Metal_v3.2.2.exe.

Source2Metal содержит опубликованную и практически проверенную SyzygyCheck v2.2.0 как единственную извлекаемую утилиту.

Исходный код намеренно не дублируется внутри EXE или пользовательского пакета. Помимо Source2Metal_v3.2.2_RELEASE.zip, GitHub автоматически предоставляет Source code (zip) и Source code (tar.gz). EXE не подписан; проверяйте пакет по опубликованному SHA-256.

中文

本版继续通过 BIN2PGN v0.1.3 支持 Polyglot BIN，生成合法完整的 BOOK RAW 变例，并提供独立及合并的 CTG/BIN BOOK RAW。BIN 不生成 METAL。

这是 Source2Metal v3.2.2 的便携式 Windows 版本，无需安装。解压 ZIP 后运行 !Source2Metal_v3.2.2.exe。

Source2Metal 内含经过实际验证的 SyzygyCheck v2.2.0 正式发布包，作为唯一可解出的实用工具。

源代码不会在 EXE 或用户包内重复保存。除 Source2Metal_v3.2.2_RELEASE.zip 外，GitHub 还会自动提供 Source code (zip) 和 Source code (tar.gz)。EXE 尚未签名，请使用已发布的 SHA-256 文件验证发布包。
