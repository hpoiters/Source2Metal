SyzygyCheck v2.0.9 V9F — руководство по виртуальной памяти / файлу подкачки
============================================================================

Почему появляется это предупреждение?
--------------------------------------
Полная коллекция Syzygy может занимать много терабайт, а проверка — длиться много часов или дольше.
Windows и механизм проверки используют виртуальную память наряду с физической RAM. Отключённый или
слишком маленький файл подкачки может способствовать ошибкам выделения памяти или неожиданному прерыванию
длительной проверки.

SyzygyCheck НЕ изменяет настройки файла подкачки автоматически. Поэтому при запуске предлагается короткий
выбор: Enter = продолжить; A = выйти, чтобы сначала проверить настройки Windows.

Рекомендуемая простая настройка
-------------------------------
Для большинства систем самый простой и безопасный исходный вариант — позволить Windows автоматически
управлять размером файла подкачки и оставить достаточно свободного места на соответствующем диске. Перед
очень большой проверкой не отключайте файл подкачки и не задавайте очень маленький фиксированный максимум.

Windows 11 — пошагово
---------------------
1. Закройте SyzygyCheck, если программа ещё работает.
2. Откройте меню Пуск и найдите: Просмотр дополнительных параметров системы
3. Откройте Свойства системы.
4. Выберите вкладку Дополнительно.
5. В разделе Быстродействие выберите Параметры...
6. Снова выберите вкладку Дополнительно.
7. В разделе Виртуальная память выберите Изменить...
8. Включите: Автоматически выбирать объём файла подкачки.
9. Подтвердите кнопками OK/Применить.
10. Если Windows просит перезагрузку, перезагрузите компьютер перед длительной проверкой Syzygy.

Если автоматическое управление всё же вызывает проблемы
-------------------------------------------------------
Автоматическое управление — практичная настройка по умолчанию, но не абсолютная гарантия для любой
конфигурации Windows или экстремальной нагрузки. Если проверка многократно останавливается с ошибками
памяти/выделения при достаточном свободном месте, увеличенный начальный размер файла подкачки можно
рассмотреть как продвинутый шаг диагностики. SyzygyCheck не выбирает такие значения за пользователя.

Важно
-----
- Файл подкачки не заменяет исправную RAM и стабильное оборудование.
- На почти заполненном диске файл подкачки не может расти бесконечно.
- После изменения настроек может потребоваться перезагрузка.
- При сомнениях автоматическое управление Windows лучше маленького фиксированного ограничения.
