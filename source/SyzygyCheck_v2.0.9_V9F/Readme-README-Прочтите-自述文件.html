English

Start !SyzygyCheck_v2.0.9_V9F.exe and select the folder that contains your RTBW/RTBZ files. The checker works locally and does not upload tablebase files, filenames or results.

The verification core is based on the original Syzygy tablebase verification code by Ronald de Man. Detailed pagefile and recovery guidance is in the accompanying documentation folder. Source code is supplied separately through the Source2Metal GitHub release.
