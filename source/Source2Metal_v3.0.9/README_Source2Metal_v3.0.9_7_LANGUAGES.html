English

This remains Source2Metal v3.0.9. The ZIP contains the portable Windows EXE, the exact source archive and the release notes; no installation is required. v3.0.9 leaves Source2Metal's validated processing logic unchanged and updates the included SyzygyCheck to v2.0.9 V9F.

The purpose of this release is to preserve the proven Source2Metal workflow while providing the practically validated V9F for reliable checking of large local tablebase collections in one continuous run. Its verification core is based on the original Syzygy tablebase verification code by Ronald de Man. Tablebase files, filenames and results are not uploaded.

Extract the ZIP and start Source2Metal_v3.0.9.exe. The EXE is unsigned, so Windows may show a warning; verify it with the published SHA-256 file. Further instructions are in the INFO_EN folder of Source2Metal_v3.0.9_SOURCE.zip.
