English

This is the portable Windows release of Source2Metal v3.0.9. No installation is required. Extract the ZIP and start !Source2Metal_v3.0.9.exe. The leading exclamation mark keeps the program near the top of a folder in Windows Explorer.

Source2Metal converts supported computer-chess sources and includes the practically validated SyzygyCheck v2.0.9 V9F as the one unpackable utility. Choose main-menu option 2 > Extract separate SyzygyCheck package. The extracted checker is named !SyzygyCheck_v2.0.9_V9F.exe.

Source code is deliberately not duplicated inside the EXE or this user package. It is available separately on the GitHub release page. The EXE is unsigned, so Windows may show a warning; verify the download with the published SHA-256 file. Source2Metal and SyzygyCheck work locally and do not upload tablebase files, filenames or results.
