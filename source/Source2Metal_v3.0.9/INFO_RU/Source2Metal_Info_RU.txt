Source2Metal v3.0.9 - ИНФОРМАЦИЯ И РУКОВОДСТВО
================================================

НАЗНАЧЕНИЕ
Source2Metal — первая открытая попытка сделать самостоятельно создаваемые
дебютные книги технически более обоснованными и практически более устойчивыми
в эпоху NNUE, одновременно повышая удовольствие от компьютерных шахмат. Проект
не утверждает, что «побеждает» NNUE. Он позволяет контролируемо преобразовывать
исходный материал в RAW- и METAL-PGN для дальнейшего построения книг и обучения
Fritz. Пользователи и разработчики могут продолжать улучшать проект с помощью
OpenAI ChatGPT.

ПЕРВЫЙ ЗАПУСК И ЯЗЫК
При первом запуске Source2Metal всегда начинает на английском и спрашивает:
  Choose your default language
Доступные языки:
  1. English (English)
  2. Deutsch (German)
  3. Nederlands (Dutch)
  4. Français (French)
  5. Español (Spanish)
  6. 中文 (Chinese)
  7. Русский (Russian)
Выбор сохраняется в Source2Metal.ini рядом с EXE. При следующих запусках программа
сразу открывается на сохранённом языке. Изменить его можно через «Изменить язык».
Консоль, STATUS-файлы и отчёты используют только выбранный язык. Технические имена
папок и файлов остаются стабильными английскими именами.

ПОДДЕРЖИВАЕМЫЕ ИСТОЧНИКИ
- PGN
- CBH
- 2CBH
- полные наборы CTG/CTO/CTB

Source2Metal рекурсивно ищет только вниз от выбранной корневой папки. Родительские
папки не сканируются. Распознаваемые папки вывода Source2Metal и TEMP пропускаются.
Архивы ZIP/RAR/7z автоматически как источники не открываются.

ВЫВОД
GAME RAW
  PGN, CBH и 2CBH обрабатываются как GAME-источники. CBH/2CBH проходят через
  временный внутренний адаптер, затем через ту же RAW-проверку, что и PGN.
CTG RAW
  Каждый полный набор CTG получает собственный RAW PGN. Размер определяется
  реально декодируемым содержимым источника.
ALL SOURCES RAW
  Если существуют GAME RAW и CTG RAW, уже проверенные результаты дополнительно
  объединяются без межклассовой дедупликации.
GAME METAL
  Используется статистика позиций/ходов с учётом транспозиций. Выход состоит из
  полных легальных реальных исходных партий с исходным результатом.
CTG METAL
  Каждый CTG остаётся отдельным источником книжных данных. Сначала применяется
  строгий отбор; только при достаточном потенциале может явно использоваться
  осторожный резервный режим Small/Broad.
GAME METAL и CTG METAL намеренно остаются раздельными.

СЛОВАРЬ АНГЛИЙСКИХ ТЕХНИЧЕСКИХ ИМЁН ПАПОК
Физические имена папок одинаковы во всех языках и остаются английскими:
  REPORTS          = ОТЧЁТЫ
  Merged Sources   = Объединённые источники
  Separate Sources = Отдельные источники
  TEMP             = Временные файлы
  RAW              = Исходный/базовый вывод
  METAL            = обучающий вывод Metal
Сами английские имена папок не переводятся и не переименовываются.

СТАТУСЫ
УСПЕШНО
  Обработка завершена без ошибок и необходимых пропусков.
УСПЕШНО С ПРОПУЩЕННЫМИ ИСТОЧНИКАМИ
  Технически обработка успешна, но один или несколько источников намеренно не
  дали ответственного результата. Это не ошибка парсера.
УСПЕШНО С ОШИБКАМИ
  Обработка продолжилась, но отдельный источник или адаптер технически не сработал.
ОШИБКА
  Ошибка не позволила продолжить обработку.
Источник без ответственного результата получает не пустой вводящий в заблуждение
PGN, а STATUS.txt с объяснением причины.

FRITZ - ОБУЧЕНИЕ ИЗ БАЗЫ
Для Source2Metal Metal-PGN:
  Победы          ВКЛ.
  Поражения       ВКЛ.
  Белые           ВЫКЛ.
  Чёрные          ВЫКЛ.
  Игрок           ВЫКЛ.
  Имя игрока      ПУСТО
  Партии          ВСЕ

ПАКЕТ ИСХОДНОГО КОДА
Windows EXE содержит пакет исходного кода, соответствующий этой версии. Выберите
«Утилиты > Извлечь пакет исходного кода Source2Metal». Для опытных пользователей:
  Source2Metal_v3.0.9.exe -extract-source
Существующий идентичный пакет без необходимости не перезаписывается.

ПРОВЕРКИ
- Исходные файлы только читаются и не изменяются.
- RAW/METAL проходят структурную проверку записей там, где это применимо.
- GAME METAL дополнительно проверяет легальность реальных партий.
- Сегменты TEMP исключаются из пользовательского списка SHA-256.
- Небольшие итоговые отчёты сначала записываются во временный файл.
- При совпадении имён источников может добавляться короткий стабильный ID.
- Ввод и вывод консоли Windows явно переключаются на UTF-8, чтобы китайский и
  кириллица корректно отображались в поддерживаемых консолях Windows 10/11 и
  Windows Terminal.

ПАКЕТ ИСХОДНОГО КОДА SYZYGY
Через «Утилиты» можно извлечь точный пакет исходного кода встроенной
SyzygyCheck v2.0.9 V9F. В нём сохранены опубликованное ядро проверки, выбор
потоков, checkpoint/возобновление, компактный живой прогресс, отчётность,
проверки документации и указание исходного кода Ronald de Man.
