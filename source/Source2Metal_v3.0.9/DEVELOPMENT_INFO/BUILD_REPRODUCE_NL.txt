Source2Metal v3.0.9 - build en bronreproductie
================================================

Vereist: Go 1.23 of nieuwer.

De release gebruikt dezelfde SOURCE.zip als ingebed broncodepakket in de EXE.
De ZIP wordt bewust niet recursief in zichzelf opgenomen.

1. Pak Source2Metal_v3.0.9_SOURCE.zip uit in een lege map.
2. Kopieer diezelfde ZIP naar de bronmap als:

     embedded_source.zip

3. Test:

     go test ./...
     go vet ./...

4. Bouw Windows/amd64:

     set GOOS=windows
     set GOARCH=amd64
     set CGO_ENABLED=0
     go build -trimpath -buildvcs=false -ldflags="-s -w" -o Source2Metal_v3.0.9.exe .

Broncodepakket uit de EXE terughalen:

     Source2Metal_v3.0.9.exe -extract-source

Of start de EXE zonder parameters en kies in het startmenu:

     Hulpprogramma's > Source2Metal-broncodepakket uitpakken

De SHA-256 van het uitgepakte pakket hoort gelijk te zijn aan de ingebedde
bron-SHA-256 die Source2Metal bij Buildinformatie toont.

PERMANENTE CONSISTENTIECONTROLE
================================
`go test ./...` en `Source2Metal_v3.0.9.exe -selftest` voeren automatisch de
release-consistentiecontrole uit. Die controle vergelijkt versies, menu- en
uitpadroutes, de embedded SyzygyCheck-programma- en broncodepakketten, README/INFO-
verwijzingen en de bron-ZIP die in de EXE zit. Verwijder of omzeil deze controle
niet bij latere wijzigingen.

SyzygyCheck-broncode uitpakken:
  via Hulpprogramma's > SyzygyCheck-broncodepakket uitpakken (ZIP)
  of: Source2Metal_v3.0.9.exe -extract-syzygy-source
