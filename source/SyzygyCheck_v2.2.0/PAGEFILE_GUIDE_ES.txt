SyzygyCheck v2.2.0 — guía de memoria virtual / archivo de paginación
=======================================================================

¿Por qué aparece esta advertencia?
----------------------------------
Una colección Syzygy completa puede ocupar muchos terabytes y una comprobación puede durar muchas horas
o más. Windows y el motor de verificación utilizan memoria virtual además de la RAM física. Un archivo de
paginación desactivado o demasiado pequeño puede contribuir a errores de memoria/asignación o a una
interrupción inesperada durante una comprobación prolongada.

SyzygyCheck NO cambia automáticamente la configuración del archivo de paginación. Al iniciar ofrece una
elección breve: Enter = continuar; A = abortar para revisar primero la configuración de Windows.

Configuración sencilla recomendada
----------------------------------
Para la mayoría de los sistemas, el punto de partida más sencillo y seguro es dejar que Windows administre
automáticamente el tamaño del archivo de paginación y mantener suficiente espacio libre en la unidad que
lo contiene. No desactive el archivo de paginación ni imponga un límite fijo muy pequeño antes de una
comprobación excepcionalmente grande.

Windows 11 — paso a paso
------------------------
1. Cierre SyzygyCheck si todavía está ejecutándose.
2. Abra Inicio y busque: Ver la configuración avanzada del sistema
3. Abra Propiedades del sistema.
4. Seleccione la pestaña Opciones avanzadas.
5. En Rendimiento, seleccione Configuración...
6. Seleccione de nuevo Opciones avanzadas.
7. En Memoria virtual, seleccione Cambiar...
8. Active: Administrar automáticamente el tamaño del archivo de paginación para todas las unidades.
9. Confirme con Aceptar/Aplicar.
10. Si Windows solicita reiniciar, reinicie antes de iniciar una comprobación Syzygy larga.

Si la administración automática sigue dando problemas
-----------------------------------------------------
La administración automática es una configuración práctica por defecto, pero no una garantía absoluta
para todas las configuraciones de Windows o cargas extremas. Si la comprobación se detiene repetidamente
con errores de memoria/asignación pese a disponer de espacio libre, puede considerarse un tamaño inicial
mayor como paso avanzado. SyzygyCheck no elige esos valores por usted.

Importante
----------
- El archivo de paginación no sustituye a una RAM defectuosa ni a hardware inestable.
- En una unidad casi llena no puede crecer indefinidamente.
- Puede ser necesario reiniciar después de cambiar la configuración.
- En caso de duda, la administración automática de Windows es mejor punto de partida que un límite pequeño.
