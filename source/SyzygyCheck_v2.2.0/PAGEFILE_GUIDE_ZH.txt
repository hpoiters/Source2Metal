SyzygyCheck v2.2.0 — 虚拟内存 / 页面文件指南
=============================================

为什么会显示此提示？
------------------
完整的 Syzygy 数据库可能达到数 TB，校验可能持续数小时甚至更久。除物理内存 RAM 外，Windows 和
校验引擎还会使用虚拟内存。页面文件被关闭或设置得过小，在大型、长时间校验中可能导致内存/分配错误
或意外中断。

SyzygyCheck 不会自动修改 Windows 的页面文件设置。因此启动时只提供一个简短选择：Enter = 继续；
A = 退出，以便先检查或修改 Windows 设置。

推荐的简单设置
--------------
对大多数系统而言，最简单、较安全的起点是让 Windows 自动管理页面文件大小，并确保页面文件所在
驱动器有足够的可用空间。在进行超大型校验前，不建议关闭页面文件，也不要设置很小的固定上限。

Windows 11 — 操作步骤
---------------------
1. 如果 SyzygyCheck 仍在运行，请先退出。
2. 打开“开始”，搜索：查看高级系统设置
3. 打开“系统属性”。
4. 选择“高级”选项卡。
5. 在“性能”下选择“设置...”。
6. 再次选择“高级”选项卡。
7. 在“虚拟内存”下选择“更改...”。
8. 勾选：自动管理所有驱动器的分页文件大小。
9. 使用“确定/应用”确认。
10. 如果 Windows 要求重新启动，请先重启，再进行长时间 Syzygy 校验。

如果自动管理仍有问题
--------------------
自动管理是实用的默认设置，但并不能保证适用于每一种 Windows 配置或极端负载。如果在磁盘空间充足
的情况下仍反复出现内存/分配错误，可把较大的页面文件初始值作为高级排错步骤。SyzygyCheck 不会替您
选择这些数值。

重要说明
--------
- 页面文件不能替代有故障的 RAM 或不稳定的硬件。
- 页面文件所在驱动器接近满盘时，页面文件不能无限增长。
- 修改设置后可能需要重新启动。
- 如有疑问，让 Windows 自动管理通常比设置很小的固定上限更合适。
