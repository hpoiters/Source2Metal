ENGLISH
Keep the complete extracted package together. Start !SyzygyCheck_v2.2.0.exe
from the folder containing the Syzygy files to be checked. Detailed information:
Docs_AL\README_AL.txt. If a report shows FAIL or ERROR, open the exact recovery
guide named in that report under Program_AL. Recommended developer source:
SyzygyCheck_v2.2.0_SOURCE.zip at https://github.com/hpoiters/SyzygyCheck
(source is not included in this package).

DEUTSCH
Lassen Sie das vollständig entpackte Paket zusammen. Starten Sie
!SyzygyCheck_v2.2.0.exe in dem Ordner mit den zu prüfenden Syzygy-Dateien.
Ausführliche Informationen: Docs_AL\README_AL.txt. Bei FAIL oder ERROR öffnen
Sie im Ordner Program_AL genau die im Bericht genannte Wiederherstellungsdatei.
Empfohlener Entwickler-Quellcode: SyzygyCheck_v2.2.0_SOURCE.zip unter
https://github.com/hpoiters/SyzygyCheck (der Quellcode ist nicht in diesem Paket enthalten).
