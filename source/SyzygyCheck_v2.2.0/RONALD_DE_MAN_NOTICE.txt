Ronald de Man / Syzygy verification core
=========================================

Based on the original Syzygy tablebase verification code by Ronald de Man.
SyzygyCheck AL uses the original tbcheck program as its verification core and does not reimplement the checksum
algorithm.

Upstream project:
https://github.com/syzygy1/tb

Upstream purpose of tbcheck:
tbcheck verifies the integrity of Syzygy tablebase files by recalculating and comparing their embedded checksums.
It accepts multiple tablebase filenames in one invocation and supports an explicit thread count.
