SyzygyCheck v2.2.0 — ALL-LANGUAGE PACKAGE GUIDE
================================================

ENGLISH
-------
- Control folder: the folder containing !SyzygyCheck_v2.2.0.exe and the Syzygy
  .rtbw/.rtbz files to be checked.
- Scope choice: control folder only [default], or control folder plus all real
  subfolders. Parent folders and symbolic links outside the boundary are not scanned.
- Whole-drive scans skip `$RECYCLE.BIN` and `System Volume Information`.
- The final progress block is separated from the report-destination menu by one
  blank line for readability.
- Result reports are stored in a CheckResult folder at the chosen destination.
- If a remembered custom destination is no longer available, a separate warning
  shows its path and states that Desktop is now the default. Enter then saves there.
- A FAIL/ERROR report gives the exact recovery path, for example
  Program_AL\SYZYGY_RECOVERY_EN.txt.
- Pagefile information: Docs_AL\PAGEFILE_GUIDE_EN.txt.
- Full English guide: Docs_AL\README_EN.txt.
- Recommended source download: SyzygyCheck_v2.2.0_SOURCE.zip. Source is not
  included in the user release package.

DEUTSCH
-------
- Prüfungsordner: der Ordner mit !SyzygyCheck_v2.2.0.exe und den zu prüfenden
  Syzygy-Dateien .rtbw/.rtbz.
- Umfang: nur dieser Ordner [Standard] oder dieser Ordner mit allen echten
  Unterordnern. Übergeordnete Ordner und externe symbolische Links werden nicht geprüft.
- Bei Prüfungen eines ganzen Laufwerks werden `$RECYCLE.BIN` und
  `System Volume Information` übersprungen.
- Zwischen dem letzten Fortschrittsblock und der Auswahl des Berichtsziels steht
  aus Gründen der Lesbarkeit genau eine Leerzeile.
- Ergebnisberichte werden am gewählten Ziel in einem CheckResult-Ordner gesammelt.
- Ist ein gespeichertes benutzerdefiniertes Ziel nicht mehr verfügbar, zeigt eine
  separate Warnung dessen Pfad und erklärt, dass der Desktop jetzt das Standardziel ist.
- Bei FAIL/ERROR nennt der Bericht den genauen Pfad, zum Beispiel
  Program_AL\SYZYGY_WIEDERHERSTELLUNG_DE.txt.
- Auslagerungsdatei: Docs_AL\PAGEFILE_GUIDE_DE.txt.
- Empfohlener Quellcode-Download: SyzygyCheck_v2.2.0_SOURCE.zip. Der Quellcode
  ist nicht im Benutzerpaket enthalten.

NEDERLANDS
----------
- Controlemap: de map met !SyzygyCheck_v2.2.0.exe en de te controleren Syzygy-
  bestanden .rtbw/.rtbz.
- Bereik: alleen deze Controlemap [standaard], of deze Controlemap met alle echte
  submappen. Bovenliggende mappen en externe symbolische links worden niet gecontroleerd.
- Bij een controle van een volledige schijf worden `$RECYCLE.BIN` en
  `System Volume Information` overgeslagen.
- Tussen het laatste voortgangsblok en de keuze voor de rapportbestemming staat
  voor de leesbaarheid precies één witregel.
- Resultaatrapporten worden op de gekozen bestemming verzameld in de map CheckResult.
- Als een onthouden eigen bestemming niet meer beschikbaar is, toont een afzonderlijke
  waarschuwing het oude pad en meldt zij dat Desktop nu de standaard is. Enter slaat daar op.
- Bij FAIL/ERROR noemt het rapport het exacte herstelpad, bijvoorbeeld
  Program_AL\SYZYGY_HERSTEL_NL.txt.
- Pagefile-informatie: Docs_AL\PAGEFILE_GUIDE_NL.txt.
- Volledige Nederlandse handleiding: Docs_AL\README_NL.txt.
- Aanbevolen broncodedownload: SyzygyCheck_v2.2.0_SOURCE.zip. De source zit niet
  in het gebruikerspakket.

FRANÇAIS
--------
- Dossier contrôlé : dossier contenant !SyzygyCheck_v2.2.0.exe et les fichiers
  Syzygy .rtbw/.rtbz à vérifier.
- Étendue : ce dossier uniquement [défaut], ou ce dossier avec tous ses vrais
  sous-dossiers. Les dossiers parents et les liens symboliques externes sont exclus.
- Lors du contrôle d’un disque entier, `$RECYCLE.BIN` et
  `System Volume Information` sont ignorés.
- Une ligne vide sépare le dernier bloc de progression du choix de destination
  du rapport afin d'améliorer la lisibilité.
- Les rapports sont regroupés dans un dossier CheckResult à l'emplacement choisi.
- Si une destination personnalisée mémorisée n’est plus disponible, un avertissement
  séparé affiche son chemin et indique que le Bureau est désormais la destination par défaut.
- En cas de FAIL/ERROR, le rapport indique le chemin exact, par exemple
  Program_AL\SYZYGY_RECUPERATION_FR.txt.
- Mémoire virtuelle : Docs_AL\PAGEFILE_GUIDE_FR.txt.
- Téléchargement recommandé du code source : SyzygyCheck_v2.2.0_SOURCE.zip.
  Le code source n'est pas inclus dans le paquet utilisateur.

ESPAÑOL
-------
- Carpeta comprobada: la carpeta con !SyzygyCheck_v2.2.0.exe y los archivos
  Syzygy .rtbw/.rtbz que se van a comprobar.
- Alcance: solo esta carpeta [predeterminado], o esta carpeta y todas sus
  subcarpetas reales. No se examinan carpetas superiores ni enlaces externos.
- Al comprobar un disco completo se omiten `$RECYCLE.BIN` y
  `System Volume Information`.
- Una línea en blanco separa el bloque final de progreso del menú de destino
  del informe para facilitar la lectura.
- Los informes se agrupan en una carpeta CheckResult en el destino elegido.
- Si un destino personalizado recordado ya no está disponible, un aviso separado
  muestra su ruta e indica que el Escritorio es ahora el destino predeterminado.
- En caso de FAIL/ERROR, el informe indica la ruta exacta, por ejemplo
  Program_AL\SYZYGY_RECUPERACION_ES.txt.
- Memoria virtual: Docs_AL\PAGEFILE_GUIDE_ES.txt.
- Descarga recomendada del código fuente: SyzygyCheck_v2.2.0_SOURCE.zip.
  El código fuente no se incluye en el paquete para usuarios.

中文
----
- 检查文件夹：包含 !SyzygyCheck_v2.2.0.exe 和待检查 Syzygy .rtbw/.rtbz 文件的文件夹。
- 检查范围：仅检查此文件夹 [默认]，或检查此文件夹及其所有真实子文件夹。不会检查上级文件夹，
  也不会沿外部符号链接越过边界。
- 检查整个磁盘时会跳过 `$RECYCLE.BIN` 和 `System Volume Information`。
- 为便于阅读，最终进度块与报告保存位置菜单之间保留一行空白。
- 结果报告会保存在所选位置的“检查结果”文件夹中。
- 如果记住的自定义保存位置不再可用，程序会单独显示警告及原路径，并说明桌面现在是默认位置；
  按回车键后，报告将保存到桌面。
- 如出现 FAIL/ERROR，报告会给出准确路径，例如 Program_AL\SYZYGY_RECOVERY_ZH.txt。
- 页面文件说明：Docs_AL\PAGEFILE_GUIDE_ZH.txt。
- 推荐的源代码下载：SyzygyCheck_v2.2.0_SOURCE.zip。源代码不包含在用户发布包中。

РУССКИЙ
-------
- Проверяемая папка: папка с !SyzygyCheck_v2.2.0.exe и проверяемыми файлами
  Syzygy .rtbw/.rtbz.
- Область: только эта папка [по умолчанию] либо эта папка и все настоящие
  подпапки. Родительские папки и внешние символические ссылки не проверяются.
- При проверке всего диска папки `$RECYCLE.BIN` и
  `System Volume Information` пропускаются.
- Для удобства чтения последний блок прогресса отделён от выбора места отчёта
  одной пустой строкой.
- Отчёты собираются в папке РезультатПроверки в выбранном месте.
- Если сохранённое пользовательское место больше недоступно, отдельное предупреждение
  показывает прежний путь и сообщает, что рабочий стол теперь используется по умолчанию.
- При FAIL/ERROR отчёт указывает точный путь, например
  Program_AL\SYZYGY_RECOVERY_RU.txt.
- Файл подкачки: Docs_AL\PAGEFILE_GUIDE_RU.txt.
- Рекомендуемая загрузка исходного кода: SyzygyCheck_v2.2.0_SOURCE.zip.
  Исходный код не включён в пользовательский пакет.
