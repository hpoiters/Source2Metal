Source2Metal v3.0.10 — MANUEL UTILISATEUR (FRANÇAIS)
===================================================

1. OBJECTIF
Source2Metal est un outil portable Windows x64 pour inventorier et traiter des
sources d’échecs informatiques. Il accepte PGN, les ensembles CTG/CTO/CTB
complets, les ensembles CBH classiques et les ensembles 2CBH. Il peut produire
des PGN RAW neutres et des matériaux GAME-METAL et CTG-METAL séparés.

2. DÉMARRAGE
Décompressez entièrement Source2Metal_v3.0.10_RELEASE.zip. Gardez ensemble l’EXE,
la courte introduction HTML et le dossier Docs. Placez
!Source2Metal_v3.0.10.exe dans le dossier contenant les sources ; les
sous-dossiers sont parcourus automatiquement. Aucune installation n’est requise.

Le programme ignore .git, TEMP, Tijdelijk, les dossiers finissant par _output et
son propre dossier !Source2Metal_Output. Il lit les sources et écrit les
résultats dans un nouveau dossier horodaté.

3. ENSEMBLES COMPLETS
- PGN : un fichier .pgn.
- CTG : fichiers .ctg, .cto et .ctb correspondants.
- CBH : fichiers .cbh, .cbg, .cbp et .cbt correspondants.
- 2CBH : fichiers .2cbh, .2cbg et .2lid correspondants.
Les ensembles incomplets sont signalés et ne sont jamais traités silencieusement
comme complets.

4. MENU PRINCIPAL
1 = Traiter les sources [défaut]
2 = SyzygyCheck / fichier d’échange
3 = Changer de langue
4 = Informations de compilation
0 = Quitter

5. TRAITEMENT
Choisissez d’abord le nombre de workers. Par défaut, la moitié des threads CPU
logiques disponibles pour le processus est utilisée.

Mode 1 : inventaire et rapport seulement.
Mode 2 : RAW ; PGN/CBH/2CBH deviennent GAME RAW et chaque CTG complet devient
CTG RAW. Si les deux classes existent, ALL SOURCES RAW est aussi créé.
Mode 3 [défaut] : RAW plus résultats GAME-METAL et CTG-METAL séparés.

Pour les modes 2 et 3, choisissez la profondeur RAW (1–120 ply ; défaut 100),
la longueur minimale (1–120 ply ; défaut 24), le filtre Elo facultatif et
l’écart Elo maximal. Elo 0 conserve la sélection source ; 1 exige les deux
joueurs >=2500 ; 2 exige les deux joueurs >=2400.

6. RÉSULTATS
Les résultats sont enregistrés sous :
  !Source2Metal_Output\AAAA-MM-JJ_HH-MM-SS\
Le dossier contient RAW et/ou METAL ainsi que REPORTS. Les résultats par source
et fusionnés restent identifiables. Les fichiers temporaires des adaptateurs
sont supprimés à la fin. Les rapports donnent paramètres, sources, état,
informations de compilation et sommes SHA-256.

GAME-METAL contient des parties source légales complètes avec leur résultat
d’origine et utilise les statistiques de positions/transpositions. CTG-METAL
utilise des preuves orientées livre. Ils restent séparés car leur sens diffère.

Pour Fritz « Apprendre de la base » avec un PGN Metal : Victoires ACTIVÉ,
Défaites ACTIVÉ, Blanc DÉSACTIVÉ, Noir DÉSACTIVÉ, Joueur DÉSACTIVÉ, nom vide,
Parties TOUTES.

7. SyzygyCheck v2.2.0
Choisissez le menu principal 2 puis l’option 1. Source2Metal écrit
SyzygyCheck_v2.2.0_UTILITY.zip près de l’EXE. Décompressez tout le paquet et
lisez 1_READ_FIRST_AL.txt. Source2Metal ne lance pas SyzygyCheck.

8. SOURCE, CONFIDENTIALITÉ ET INTÉGRITÉ
Le code source n’est inclus ni dans l’EXE ni dans Source2Metal_v3.0.10_RELEASE.zip.
GitHub le fournit automatiquement sous Source code (zip) et Source code (tar.gz).
Aucune archive source personnalisée supplémentaire n’est publiée, car elle ne
ferait que dupliquer ces téléchargements. Les programmes travaillent localement et ne téléversent ni sources,
ni noms de tablebases, ni résultats. Vérifiez les téléchargements avec
SHA256_Source2Metal_v3.0.10.txt. L’EXE n’est pas encore signé ; Windows peut
donc afficher Éditeur inconnu ou SmartScreen.
