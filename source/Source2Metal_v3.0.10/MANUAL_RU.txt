Source2Metal v3.0.10 — РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ (РУССКИЙ)
==========================================================

1. НАЗНАЧЕНИЕ
Source2Metal — переносимая программа Windows x64 для инвентаризации и обработки
источников компьютерных шахмат. Поддерживаются PGN, полные наборы CTG/CTO/CTB,
классические наборы CBH и наборы 2CBH. Программа создаёт нейтральные RAW PGN и
раздельный учебный материал GAME-METAL и CTG-METAL.

2. ЗАПУСК
Полностью распакуйте Source2Metal_v3.0.10_RELEASE.zip. Храните вместе EXE, краткое
введение HTML и папку Docs. Поместите !Source2Metal_v3.0.10.exe в папку с
исходными файлами; подпапки просматриваются автоматически. Установка не нужна.

Программа пропускает .git, TEMP, Tijdelijk, папки с окончанием _output и свою
папку !Source2Metal_Output. Источники только читаются, а результаты записываются
в новую папку с отметкой времени.

3. ПОЛНЫЕ НАБОРЫ ИСТОЧНИКОВ
- PGN: один файл .pgn.
- CTG: соответствующие файлы .ctg, .cto и .ctb.
- CBH: соответствующие файлы .cbh, .cbg, .cbp и .cbt.
- 2CBH: соответствующие файлы .2cbh, .2cbg и .2lid.
Неполные наборы отмечаются и не считаются полными без предупреждения.

4. ГЛАВНОЕ МЕНЮ
1 = Обработать источники [по умолчанию]
2 = SyzygyCheck / файл подкачки
3 = Изменить язык
4 = Информация о сборке
0 = Выход

5. ПАРАМЕТРЫ ОБРАБОТКИ
Сначала выберите число рабочих потоков. По умолчанию используется половина
логических потоков CPU, доступных процессу.

Режим 1: только инвентаризация и отчёт.
Режим 2: RAW; PGN/CBH/2CBH становятся GAME RAW, а каждый полный CTG — CTG RAW.
При наличии обоих классов также создаётся ALL SOURCES RAW.
Режим 3 [по умолчанию]: RAW плюс раздельные GAME-METAL и CTG-METAL.

Для режимов 2 и 3 выберите глубину RAW (1–120 полуходов; по умолчанию 100),
минимальную длину партии (1–120; по умолчанию 24), дополнительный фильтр Elo и
максимальную разницу Elo. Elo 0 сохраняет отбор источника; 1 требует обоих
игроков >=2500; 2 требует обоих игроков >=2400.

6. РЕЗУЛЬТАТЫ
Результаты записываются в:
  !Source2Metal_Output\ГГГГ-ММ-ДД_ЧЧ-ММ-СС\
Папка запуска содержит RAW и/или METAL и REPORTS. Результаты отдельных источников
и объединённые результаты остаются различимыми. Временные файлы адаптеров
удаляются в конце. Отчёты содержат настройки, источники, статус, сведения о
сборке и контрольные суммы SHA-256.

GAME-METAL содержит полные легальные исходные партии с исходным результатом и
использует статистику позиций/транспозиций. CTG-METAL использует книжные
свидетельства. Они разделены, поскольку смысл этих свидетельств различен.

Для Fritz «Обучение из базы» с Metal PGN: Победы ВКЛ, Поражения ВКЛ, Белые ВЫКЛ,
Чёрные ВЫКЛ, Игрок ВЫКЛ, имя игрока пустое, Партии ВСЕ.

7. SyzygyCheck v2.2.0
Выберите пункт 2 главного меню, затем пункт 1. Source2Metal создаст рядом с EXE
файл SyzygyCheck_v2.2.0_UTILITY.zip. Полностью распакуйте его и прочтите
1_READ_FIRST_AL.txt. Source2Metal сам не запускает SyzygyCheck.

8. ИСХОДНЫЙ КОД, КОНФИДЕНЦИАЛЬНОСТЬ И ЦЕЛОСТНОСТЬ
Исходный код не встроен в EXE или Source2Metal_v3.0.10_RELEASE.zip. GitHub
автоматически предоставляет его как Source code (zip) и Source code (tar.gz).
Дополнительный пользовательский архив исходного кода не публикуется, поскольку
он только дублировал бы эти загрузки. Программы работают
локально и не отправляют источники, имена файлов tablebase или результаты.
Проверяйте загрузки по SHA256_Source2Metal_v3.0.10.txt. EXE пока не подписан,
поэтому Windows может показать «Неизвестный издатель» или SmartScreen.
