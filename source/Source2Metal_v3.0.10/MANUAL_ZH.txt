Source2Metal v3.0.10 — 用户手册（中文）
=====================================

1. 用途
Source2Metal 是一款便携式 Windows x64 工具，用于盘点和处理计算机国际象棋源资料。
它支持 PGN、完整 CTG/CTO/CTB 文件组、经典 CBH 文件组和 2CBH 文件组，可生成
中性的 RAW PGN，以及彼此分开的 GAME-METAL 与 CTG-METAL 学习材料。

2. 启动
完整解压 Source2Metal_v3.0.10_RELEASE.zip。请将 EXE、简短 HTML 介绍和 Docs 文件夹保存在
一起。把 !Source2Metal_v3.0.10.exe 放入源文件所在文件夹；程序会自动搜索其
子文件夹。无需安装。

程序会跳过 .git、TEMP、Tijdelijk、名称以 _output 结尾的文件夹，以及它自己的
!Source2Metal_Output 文件夹。源文件只被读取；结果写入新的时间戳输出文件夹。

3. 完整源文件组
- PGN：一个 .pgn 文件。
- CTG：相互匹配的 .ctg、.cto 和 .ctb 文件。
- CBH：相互匹配的 .cbh、.cbg、.cbp 和 .cbt 文件。
- 2CBH：相互匹配的 .2cbh、.2cbg 和 .2lid 文件。
不完整的文件组会明确报告，不会被静默当作完整文件组处理。

4. 主菜单
1 = 处理源文件 [默认]
2 = SyzygyCheck / 页面文件
3 = 更改语言
4 = 构建信息
0 = 退出

5. 处理选项
首先选择 worker 数。默认使用当前进程可用逻辑 CPU 线程的一半。

模式 1：仅盘点源文件并写报告。
模式 2：构建 RAW；PGN/CBH/2CBH 生成 GAME RAW，每个完整 CTG 生成 CTG RAW。
两类都存在时还会生成 ALL SOURCES RAW。
模式 3 [默认]：构建 RAW，并分别生成 GAME-METAL 与 CTG-METAL。

模式 2 和 3 还需选择 RAW 最大深度（1–120 ply，默认 100）、最短对局长度
（1–120 ply，默认 24）、可选 Elo 过滤器及最大 Elo 差。Elo 选项 0 保留源选择；
选项 1 要求双方 >=2500；选项 2 要求双方 >=2400。

6. 输出
结果写入：
  !Source2Metal_Output\YYYY-MM-DD_HH-MM-SS\
运行文件夹包含 RAW 和/或 METAL 结果以及 REPORTS。每个源的结果与合并结果保持
可区分。临时适配器文件在结束时删除。报告包含设置、源、状态、构建信息和
SHA-256 校验值。

GAME-METAL 保存带原始赛果的完整合法源对局，并使用局面/转置统计。CTG-METAL
使用面向开局库的证据。由于证据含义不同，两者会刻意保持分开。

在 Fritz 中使用 Metal PGN“从数据库学习”：胜局 开，负局 开，白方 关，黑方 关，
棋手 关，棋手名留空，对局 全部。

7. SyzygyCheck v2.2.0
选择主菜单 2，再选择选项 1。Source2Metal 会在 EXE 旁写出
SyzygyCheck_v2.2.0_UTILITY.zip。请完整解压并阅读 1_READ_FIRST_AL.txt。
Source2Metal 本身不会运行 SyzygyCheck。

8. 源代码、隐私与完整性
源代码不嵌入 EXE，也不放入 Source2Metal_v3.0.10_RELEASE.zip。GitHub 会自动提供
Source code (zip) 和 Source code (tar.gz)。不会另外发布自定义源代码 ZIP，因为那只会
重复这两个下载。两个程序都在本地工作，不上传源文件、tablebase 文件名或结果。
请用 SHA256_Source2Metal_v3.0.10.txt 验证用户发布包和 EXE。
EXE 目前未签名，因此 Windows 可能显示“未知发布者”或 SmartScreen 警告。
