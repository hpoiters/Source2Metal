Source2Metal v3.0.10 - release notes
===================================

Source2Metal v3.0.10 neemt de actuele zelfstandige SyzygyCheck v2.2.0-release
op als ingebouwde, uitpakbare utility. De conversiecode, broninventarisatie,
adapters, RAW-, GAME-METAL-, CTG-METAL- en leerlogica van Source2Metal zijn niet
gewijzigd.

Nieuwe SyzygyCheck-integratie:
- De ingebedde utility is byte-voor-byte gelijk aan het op GitHub gepubliceerde
  `SyzygyCheck_v2.2.0_RELEASE.zip`.
- SyzygyCheck kan alleen de gekozen controlemap of de controlemap met alle echte
  submappen controleren. Bovenliggende mappen en symbolische links worden niet
  gevolgd.
- Checkpoints bewaren relatieve submappaden. Een onderbroken run kan veilig
  hervatten; een gedeeltelijke batch mag daarbij bewust opnieuw worden
  gecontroleerd.
- FAIL en ERROR tonen het volledige Windows-pad. Herstelhandleidingen staan op
  het in elk van de zeven talen genoemde pad onder `Program_AL`.
- Het resultaatrapport kan naar het bureaublad, de controlemap of een vrij
  gekozen map. Een verdwenen onthouden map geeft eerst een duidelijke melding
  en zet het bureaublad terug als standaard.
- De checker behoudt de gevalideerde checksumkern, threadkeuze, live
  leessnelheid, voortgang, zelftest en rapportage.
- Praktijkvalidatie omvat de geslaagde test met bewust defect gemaakte
  tablebasebestanden en een geslaagde stop-/hervatproef. De grote controle van
  3022 7-man-bestanden liep tijdens vrijgave stabiel door.

Opschoning van de distributie:
- De hoofd-EXE heet `!Source2Metal_v3.0.10.exe` en blijft daardoor in Windows
  Verkenner bovenaan zichtbaar.
- `Source2Metal_v3.0.10_RELEASE.zip` bevat geen broncode. GitHub biedt de broncode
  automatisch afzonderlijk aan als `Source code (zip)` en `Source code (tar.gz)`.
- De EXE bevat evenmin een Source2Metal- of SyzygyCheck-bronarchief.
- Alleen de actuele SyzygyCheck v2.2.0 blijft als echte geneste utility
  aanwezig. Na uitpakken bevat die utility `!SyzygyCheck_v2.2.0.exe`,
  `1_READ_FIRST_AL.txt`, `Docs_AL` en `Program_AL`.
- De SyzygyCheck-utility bevat geen source-ZIP, repository-ZIP, MakeMem,
  validatiebundel of oude programmaversie.
- De korte gebruikersintro is één HTML-bestand met springlinks voor Engels,
  Russisch en Chinees: `Readme-README-Прочтите-自述文件.html`.
- De HTML-intro verwijst naar de volledige handleidingen in alle zeven talen in
  `Docs-DOCUMENTATION-Документация-文档`: EN, DE, NL, FR, ES, RU en ZH.
- Naast de gebruikersrelease toont GitHub automatisch `Source code (zip)` en
  `Source code (tar.gz)`. Er is bewust geen extra, vrijwel identieke
  handmatig samengesteld source-archief; de source is niet ingebouwd.
- Oude Source2Metal- en SyzygyCheck-versies zijn uit de actuele bronboom
  verwijderd. Zij blijven behouden in Gitgeschiedenis en eerdere releases.

De releasecontrole bewaakt de twee bestandsnamen met uitroepteken, de vier
zichtbare GitHub-downloads, de drie springlinktalen, alle zeven volledige
handleidingen in de Docs-map, alle 22 bestanden van de SyzygyCheck-utility,
actuele versienummers, herstelpaden, SHA-256 en de canonieke credit voor
Ronald de Man.
