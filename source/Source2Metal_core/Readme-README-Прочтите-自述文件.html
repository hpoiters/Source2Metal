Source2Metal v3.4.1-RC3 — allgemeine Anleitung

1. Eingabe
Eigene Quellen verwenden: PGN/CBH/2CBH sind GAME-Quellen; vollständige CTG/CTO/CTB-Sätze und BIN sind BOOK-Quellen. ZIP und EXE werden nicht als Quellen verarbeitet. Quelldateien werden nur gelesen.
PGN-Eröffnungslinien ausdrücklich über OVERLAY wählen: Dateien in den Unterordner OVERLAY-PGN des Eingabeordners legen oder die Endung .overlay.pgn verwenden. Bestimmte Dateinamen, Bücher oder Dateizahlen sind nicht vorgeschrieben. Unbeabsichtigte GAME-Kopien derselben Dateien vermeiden. Ergebnis * allein wählt OVERLAY nicht aus.

2. Verarbeitung
Paket entpacken und !Source2Metal_v3.4.1-RC3.exe bei den Eingaben starten. Sprache und Quellenverarbeitung wählen. RAW + METAL erzeugt die endgültige Metal.pgn; RAW allein nicht. Standardtiefe: 100 Halbzüge. Separate CTG-Tiefe 0 bedeutet ohne vorgegebenes Tiefenlimit. Standardmäßig wird die Hälfte der logischen CPU-Threads, aufgerundet, verwendet; einstellbar. Ausgabeordner werden nicht erneut eingelesen.
CLI: --input PATH --mode all --workers 6 --max-ply 100 --no-pause
SyzygyCheck lässt sich als separates Hilfsprogramm über das Menü entpacken.

3. OVERLAY-Regeln
Mehrzeilige Kommentare bleiben im Datensatz. Nicht geschlossene Kommentare/Varianten oder unpassende Schlusszeichen erzeugen einen Quellfehler und stoppen diese Quelle; kein gültiger Anfang eines beschädigten Datensatzes wird akzeptiert. Unbrauchbare GAME-Ergebnisse blockieren dagegen nicht mit einer Tastaturabfrage.

4. Ausgabe und Anwendung
Ausgaben: !Source2Metal_Output mit Zeitstempel. RAW enthält getrennte und zusammengeführte Quellen; GAME und BOOK bleiben getrennt. BIN liefert weiterhin nur RAW. CTG METAL bewahrt dekodierte erreichbare Buchzüge als neutrale Linien; GAME-METAL wählt Modellpartien nach den bisherigen Regeln.
Der Parser liest Hauptlinien und normalisiert legale Züge zu kanonischer SAN. Die gesamte ursprüngliche Hauptlinie wird auf Legalität geprüft; danach gilt die RAW-Tiefengrenze (Standard: 100 Halbzüge). GAME-Längen- und Elo-Filter gelten nicht. Kommentare, Anmerkungen und Buchgewichte dienen nicht als Zuggewichte; die Ausgabe erhält Ergebnis * und neutrale Tags.
Nur exakt gleiche vollständige kanonische Zugfolgen werden dedupliziert, unabhängig von Tags oder Ergebnis. Bei einer Tiefengrenze wird die vollständige BEIBEHALTENE Folge verglichen: Unterschiede erst jenseits der Grenze können entfallen. Präfixe bleiben bei unterschiedlicher beibehaltener Länge getrennt. Zugumstellungen bleiben bei unterschiedlicher Zugfolge erhalten, auch bei gleicher Endstellung. Vorhandene Modellpartien haben Vorrang; ihr Ergebnis und ihre Bytes bleiben erhalten. Overlay liefert keine GAME-Statistik. Strukturelle Fehler wie nicht geschlossene Kommentare werden als Quellenfehler gemeldet.
REPORTS/Source2Metal_Overlay_Report.txt zeigt je Quelle Read, Accepted, Rejected, Deduplicated, RAW, Exact full-line duplicates, Final Metal contribution und neue Paare. Accepted = Deduplicated + RAW; Read = Accepted + Rejected. RAW-Modus ergänzt METAL nicht.

5. Grenzen und Validierung
CTG-Berichte: Positions/Edges, ExportedEdges, DepthCutMoves, DecodeErrors. CompleteCTG bleibt false. Unterverwandlungen und besondere bauernlose Symmetrien sind eingeschränkt; erkannte Verwandlungen nehmen eine Dame an. RawFooter-Statistikbytes belegen keine Fritz-Lerngewichte.
RC3 wurde unter Linux getestet und für Windows 64-Bit gebaut. Eine anschließende Windows-Praxisprüfung wurde erfolgreich abgeschlossen; die bereitgestellten Berichte bestätigen das erwartete Ergebnis. Programmdateien und Go-Quellcode entsprechen unverändert der getesteten RC3. Source2Metal_v3.4.1-RC3_SOURCE.zip enthält Quellcode und Tests; nur in einen separaten Entwicklungsordner entpacken.

Source2Metal v3.4.1-RC3 — general manual

1. Select input
Use your own sources. Ordinary PGN/CBH/2CBH files are GAME sources; complete CTG/CTO/CTB sets and BIN files are BOOK sources. ZIP and EXE files are not inputs. Sources are read-only.
For PGN opening lines, explicitly choose OVERLAY: put the desired files in an OVERLAY-PGN subfolder of your input folder, or use the .overlay.pgn suffix. No particular names, books or number of files are required. Avoid leaving unintended GAME copies of overlay sources elsewhere in the input tree. Result * alone never selects OVERLAY.

2. Run processing
Extract the package and start !Source2Metal_v3.4.1-RC3.exe beside your inputs. Select a language and source processing. Choose RAW or RAW + METAL; the latter produces final Metal.pgn. RAW defaults to 100 plies. Separate CTG depth 0 means no preset CTG depth cap. Workers default to half the logical CPU threads, rounded up, and are adjustable. Output directories are excluded from input scanning.
CLI: --input PATH --mode all --workers 6 --max-ply 100 --no-pause
The menu can extract the separate SyzygyCheck utility; Source2Metal does not check tablebases itself.

3. OVERLAY rules
Opening coverage is imported; original Polyglot weights, keys and record numbers are NOT transferred. Results become neutral *. No wins or new engine analysis are invented.
Multiline comments stay in their record. Unclosed comments/variations or unmatched closing delimiters cause an explicit source error and stop that source; a damaged record's valid prefix is not accepted. Unusable GAME results instead allow automatic continuation without a keyboard prompt.

4. Understand and use output
Outputs are placed under !Source2Metal_Output in a timestamped directory. RAW holds separate and merged sources, separating GAME and BOOK. BIN still produces RAW only. CTG METAL preserves decoded reachable book moves through neutral lines. GAME-METAL selects model games using the existing rules.
The parser reads mainlines and normalizes legal moves to canonical SAN. It validates the entire original mainline, then applies the RAW depth limit (default 100 plies). GAME length and Elo filters do not apply. Comments, annotations and book weights are not used as move weights; output uses result * and neutral tags.
Only exactly identical complete canonical move sequences are deduplicated, regardless of tags or result. At a depth limit, the complete RETAINED sequence is compared: lines differing only beyond the limit can therefore merge. Prefixes remain separate when retained lengths differ. Transpositions remain separate when move order differs, even with the same final position. Existing model games take precedence; their result and bytes are preserved. Overlay contributes no GAME statistics. Structural damage such as an unclosed comment is reported as a source error.
REPORTS/Source2Metal_Overlay_Report.txt lists Read, Accepted, Rejected, Deduplicated, RAW, Exact full-line duplicates, Final Metal contribution and new position/move pairs per source. Accepted = Deduplicated + RAW; Read = Accepted + Rejected. RAW-only mode adds nothing to METAL.

5. Limits and validation
CTG reports list Positions/Edges, ExportedEdges, DepthCutMoves and DecodeErrors. CompleteCTG remains false; full format support is unproven. Underpromotion and special pawnless symmetry are limited; recognized promotions assume a queen. RawFooter contains original statistics bytes, not proof of Fritz learning weights.
RC3 was tested on Linux and built for Windows 64-bit. A subsequent Windows practice run completed successfully; the supplied reports confirm the expected result. Executables and Go source are unchanged from the tested RC3. Source and tests are in Source2Metal_v3.4.1-RC3_SOURCE.zip; extract it only into a separate development directory.

Place PGN files in OVERLAY-PGN beneath the selected input folder, or use the .overlay.pgn suffix. Select RAW + METAL (CLI: --mode all). RAW alone makes no final overlay contribution. Avoid unintended copies as ordinary GAME sources in the same input tree.
VoorbeeldOverlay.pgn contains six demonstration records composed specifically for this guide, without copied book data. It is ACTIVE input while inside the scanned folder. Las partidas modelo existentes tienen preferencia; se conservan su resultado y sus bytes. Overlay no aporta estadísticas GAME. Source2Metal v3.4.1-RC3 — algemene handleiding

1. Invoer kiezen
Gebruik je eigen bronnen. Gewone PGN-, CBH- en 2CBH-bestanden zijn GAME-bronnen. Complete CTG/CTO/CTB-sets en BIN-bestanden zijn BOOK-bronnen. ZIP- en EXE-bestanden zijn geen invoerbronnen. Bronnen worden alleen gelezen.
Voor korte openingslijnen in PGN gebruik je bewust de OVERLAY-route: zet de gewenste PGN-bestanden in een submap OVERLAY-PGN van de gekozen invoermap, of gebruik de bestandsuitgang .overlay.pgn. Dit geldt voor willekeurige geschikte openingsbestanden; er zijn geen verplichte namen, aantallen of specifieke boeken. Laat geen onbedoelde GAME-kopie van dezelfde overlaybron elders in de invoerboom staan. Een uitslag * alleen maakt een gewone PGN niet tot OVERLAY.

2. Verwerking starten
Pak het programmapakket uit en start !Source2Metal_v3.4.1-RC3.exe bij de invoerbestanden. Kies de gewenste taal en Bronnen verwerken. Kies RAW of RAW + METAL; voor een definitieve Metal.pgn is RAW + METAL nodig. De standaard RAW-diepte is 100 halfzetten. De aparte CTG-diepte kan daarvan afwijken; 0 betekent zonder vooraf ingestelde CTG-dieptelimiet. Standaard wordt de helft van de logische CPU-threads gebruikt, naar boven afgerond. Workers zijn instelbaar. Uitvoermappen worden uitgesloten van opnieuw inlezen.
CLI-voorbeeld: --input PATH --mode all --workers 6 --max-ply 100 --no-pause
SyzygyCheck is via het menu als apart pakket uit te pakken; Source2Metal voert geen tablebasecontrole uit.

3. Regels voor OVERLAY-PGN
De route neemt openingsdekking over, maar NIET de oorspronkelijke Polyglot-gewichten, keys of recordnummers. Uitslagen worden neutraal *. Er worden geen winstpartijen of nieuwe engine-analyses verzonnen.
Meerregelige commentaren blijven bij hun PGN-record. Onafgesloten commentaren/varianten of ongebalanceerde sluittekens geven een expliciete bronfout; alleen het geldige begin van zo'n beschadigd record wordt niet geaccepteerd. De bronverwerking stopt bij zo'n fout. Onbruikbare GAME-uitslagen geven daarentegen geen toetsvraag: verwerking gaat automatisch door.

4. Uitvoer lezen en toepassen
Resultaten staan onder !Source2Metal_Output in een map met tijdstempel. RAW bewaart afzonderlijke en samengevoegde bronnen, met GAME en BOOK gescheiden. BIN levert volgens de bestaande route alleen RAW. CTG METAL bewaart gedecodeerde bereikbare boekzetten via neutrale lijnen. GAME-METAL selecteert modelpartijen volgens de bestaande metaliseringsregels.
De parser leest hoofdlijnen en normaliseert legale zetten naar canonieke SAN. De gehele oorspronkelijke hoofdlijn wordt op legaliteit gecontroleerd; daarna geldt de ingestelde RAW-diepte (standaard 100 halfzetten). GAME-lengte- en Elo-filters gelden niet voor overlay. Commentaar, annotaties en boekgewichten worden niet als zetgewicht gebruikt; de uitvoer krijgt uitslag * en neutrale tags.
Alleen exact gelijke volledige canonieke zettenreeksen worden ontdubbeld, onafhankelijk van tags of uitslag. Bij een dieptelimiet wordt de volledige BEWAARDE reeks vergeleken: lijnen die alleen voorbij de limiet verschillen kunnen dus samenvallen. Prefixen blijven afzonderlijk behouden als de bewaarde reeksen in lengte verschillen. Transposities blijven behouden als de zettenvolgorde verschilt, ook bij dezelfde eindstelling. Bestaande modelpartijen gaan voor; hun uitslag en bytes blijven behouden. Overlay levert geen GAME-statistiek. Een fout in de structuur, zoals een onafgesloten commentaar, wordt als bronfout gemeld.
REPORTS/Source2Metal_Overlay_Report.txt geeft per bron read, accepted, rejected, duplicate, RAW, reeds gedekt, toegevoegd en nieuwe stelling-zetparen. Accepted = Deduplicated + RAW; Read = Accepted + Rejected. RAW-modus alleen voegt niets aan METAL toe.

5. Grenzen en validatie
CTG-rapporten naast RAW gebruiken Positions/Edges voor stellingen/zetten, ExportedEdges voor gedekte zetten, DepthCutMoves voor diepteafbrekingen en DecodeErrors voor decoderfouten. CompleteCTG blijft false: volledige formaatondersteuning is niet bewezen. Onderpromoties en bijzondere pionloze symmetrie zijn beperkt; herkende promoties veronderstellen een dame. RawFooter bevat oorspronkelijke statistiekbytes; deze bewijzen geen Fritz-leergewichten.

Source2Metal v3.4.1-RC3 — общее руководство

1. Входные данные
Используйте собственные источники: PGN/CBH/2CBH относятся к GAME; полные комплекты CTG/CTO/CTB и BIN — к BOOK. ZIP и EXE не являются источниками. Исходные файлы только читаются.
Для дебютных линий PGN явно выберите OVERLAY: подпапка OVERLAY-PGN входного каталога либо суффикс .overlay.pgn. Определённые имена, книги или число файлов не требуются. Не оставляйте случайные GAME-копии этих же источников. Результат * сам по себе не включает OVERLAY.

2. Обработка
Распакуйте пакет и запустите !Source2Metal_v3.4.1-RC3.exe рядом с входными файлами. Выберите язык и обработку источников. RAW + METAL создаёт итоговую Metal.pgn; только RAW — нет. Глубина RAW по умолчанию: 100 полуходов. Отдельная глубина CTG 0 означает отсутствие заданного ограничения. По умолчанию используется половина логических потоков CPU с округлением вверх; значение изменяемое. Каталоги результатов исключаются из поиска источников.
CLI: --input PATH --mode all --workers 6 --max-ply 100 --no-pause
Меню позволяет распаковать отдельную утилиту SyzygyCheck.

3. Правила OVERLAY
Многострочные комментарии остаются в записи. Незакрытые комментарии/варианты или непарные закрывающие символы вызывают явную ошибку и останавливают этот источник; корректное начало повреждённой записи не принимается. Непригодные результаты GAME, напротив, не требуют нажатия клавиш: обработка продолжается автоматически.

4. Результаты и применение
Результаты находятся в !Source2Metal_Output, в каталоге с отметкой времени. RAW содержит отдельные и объединённые источники с разделением GAME/BOOK. BIN по-прежнему создаёт только RAW. CTG METAL сохраняет декодированные достижимые ходы нейтральными линиями; GAME-METAL выбирает модельные партии по прежним правилам.
Парсер читает главные линии и нормализует легальные ходы в каноническую SAN. Проверяется вся исходная линия, затем применяется глубина RAW (по умолчанию 100 полуходов). Фильтры GAME по длине и Elo не применяются. Комментарии, аннотации и книжные веса не используются как веса ходов; выход получает результат * и нейтральные теги.
Удаляются только точно одинаковые полные канонические последовательности ходов независимо от тегов и результата. При ограничении глубины сравнивается полная СОХРАНЁННАЯ последовательность: различия за пределом глубины могут исчезнуть. Префиксы разной сохранённой длины остаются отдельными. Перестановки ходов сохраняются при различном порядке ходов, даже с одинаковой конечной позицией. Существующие модельные партии имеют приоритет; их результат и байты сохраняются. Overlay не добавляет статистику GAME. Структурные повреждения, например незакрытый комментарий, сообщаются как ошибка источника.
REPORTS/Source2Metal_Overlay_Report.txt показывает по каждому источнику Read, Accepted, Rejected, Deduplicated, RAW, Exact full-line duplicates, Final Metal contribution и новые пары. Accepted = Deduplicated + RAW; Read = Accepted + Rejected. Режим только RAW ничего не добавляет в METAL.

5. Ограничения и проверка
Отчёты CTG: Positions/Edges, ExportedEdges, DepthCutMoves, DecodeErrors. CompleteCTG остаётся false. Слабые превращения и особая симметрия беспешечных позиций ограничены; распознанные превращения предполагают ферзя. Байты RawFooter не доказывают наличие учебных весов Fritz.
RC3 проверена в Linux и собрана для Windows 64-bit. Последующий практический запуск в Windows завершился успешно; предоставленные отчёты подтверждают ожидаемый результат. Исполняемые файлы и исходный код Go не изменены по сравнению с проверенной RC3. Source2Metal_v3.4.1-RC3_SOURCE.zip содержит код и тесты; распаковывайте только в отдельный каталог разработки.

Source2Metal v3.4.1-RC3 — 通用使用说明

1. 输入来源
使用自己的文件。普通 PGN/CBH/2CBH 属于 GAME；完整 CTG/CTO/CTB 文件组及 BIN 属于 BOOK。ZIP 和 EXE 不是输入来源。源文件只读。
PGN 开局线路须明确选择 OVERLAY：放入输入目录的 OVERLAY-PGN 子目录，或使用 .overlay.pgn 后缀。不要求特定文件名、开局库或文件数量。避免在输入树其他位置留下同一文件的非预期 GAME 副本。仅有结果 * 不会自动启用 OVERLAY。

2. 启动处理
解压程序包，在输入文件旁启动 !Source2Metal_v3.4.1-RC3.exe。选择语言和来源处理。RAW + METAL 才生成最终 Metal.pgn；仅 RAW 不生成。RAW 默认深度为 100 半回合。独立 CTG 深度设为 0 表示没有预设深度上限。默认使用逻辑 CPU 线程数的一半，向上取整，可调整。输出目录不会被重新当作来源读取。
命令行：--input PATH --mode all --workers 6 --max-ply 100 --no-pause
菜单可解压独立 SyzygyCheck 工具；Source2Metal 本身不检查残局库。

3. OVERLAY 规则
多行注释保留在原记录内。未闭合的注释、变例或不配对的闭合符号会产生明确错误并停止该来源；不会接受损坏记录的合法前缀。无法使用的 GAME 结果则会自动继续，无需按键。

4. 输出与使用
输出位于 !Source2Metal_Output 的时间戳目录内。RAW 保存独立及合并来源，并区分 GAME/BOOK。BIN 仍仅生成 RAW。CTG METAL 通过中性线路保留已解码且可到达的书库着法；GAME-METAL 按既有规则选择模型对局。
解析器读取主线，将合法着法规范为标准 SAN。先检查整条原始主线是否合法，再应用 RAW 深度限制（默认 100 半回合）。GAME 长度和 Elo 过滤器不适用于 overlay。注释、评注及开局库权重不会作为着法权重使用；输出使用结果 * 和中性标签。
仅完全相同的完整规范着法序列会去重，与标签和结果无关。设置深度限制时，比较的是保留后的完整序列：仅在深度限制以外存在差异的线路可能合并。保留长度不同的前缀线路仍单独保留。着法顺序不同的换序线路也保留，即使最终局面相同。已有模型对局优先，其结果及字节保持不变。Overlay 不贡献 GAME 统计。未闭合注释等结构错误会报告为来源错误。
REPORTS/Source2Metal_Overlay_Report.txt 按来源列出 Read、Accepted、Rejected、Deduplicated、RAW、Exact full-line duplicates、Final Metal contribution 及新局面-着法对。Accepted = Deduplicated + RAW；Read = Accepted + Rejected。仅 RAW 模式不向 METAL 添加内容。

5. 限制与验证
CTG 报告含 Positions/Edges、ExportedEdges、DepthCutMoves、DecodeErrors。CompleteCTG 仍为 false，完整格式支持尚未证明。低升变及特殊无兵对称局面支持有限；识别到的升变假定升后。RawFooter 原始统计字节不证明 Fritz 学习权重。
RC3 已在 Linux 测试，并编译为 Windows 64 位程序。随后进行的 Windows 实际运行测试成功完成，所提供的报告确认结果符合预期。可执行文件和 Go 源代码与已测试的 RC3 完全相同。Source2Metal_v3.4.1-RC3_SOURCE.zip 包含源代码和测试，只应解压到独立开发目录。
