NL

Source2Metal v3.3.1

CTG METAL
Alle gedecodeerde bereikbare boekzetten blijven behouden via neutrale RAW-lijnen met uitslag *.
Geen frequentiefilter, aanbevelingen, leergewichten of kunstmatige uitslagen.
METAL/Metal.pgn voegt CTG-lijnen en geselecteerde GAME-partijen automatisch samen, zonder persoonlijke headers.
Gebruik CTG-lijnen voor boekimport; het zijn geen winst/verlies-leersignalen.
Het CTG-JSON-rapport vermeldt dekking, diepteafbrekingen en decoderbeperkingen.

Gebruik
1. Pak het RELEASE-pakket uit en zet de EXE bij de invoerbestanden.
2. Start !Source2Metal_v3.3.1.exe. Kies Nederlands en RAW of RAW + METAL.
3. Het programma stelt de helft van de logische CPU-threads voor, naar boven afgerond. Bij 36 threads: 18 workers. Dit is instelbaar.
4. RAW blijft standaard 100 halfzetten. De aparte CTG-diepte mag groter zijn; 0 betekent zonder vooraf ingestelde dieptelimiet.
5. De resultaten staan onder !Source2Metal_Output, in een map met tijdstempel. De bronnen worden alleen gelezen.
6. RAW bewaart GAME- en BOOK-bronnen gescheiden. Bij RAW + METAL staat het samengevoegde eindbestand in METAL/Metal.pgn.
7. PGN-, CBH-, 2CBH- en BIN-verwerking en het SyzygyCheck-menu blijven beschikbaar. BIN levert volgens de bestaande werkwijze alleen RAW.

De losse meegeleverde Perfect2023-PGN kan rechtstreeks als boekbasis worden geïmporteerd. Daarvoor is geen nieuwe extractie nodig. Deze PGN wordt apart geleverd; het programma bevat geen externe openingsboeken.

Rapporten
Naast elke CTG-RAW-PGN staan .ctg-report.json en .ctg-statistics.jsonl.
Positions = unieke bereikbare schaakstellingen; Edges = unieke gevonden zetten.
ExportedEdges = in de PGN vertegenwoordigde zetten; CoverageOfDecodedEdges = dekking van de gedecodeerde structuur.
DepthCutMoves = zetten buiten de dieptelimiet; DecodeErrors = overgeslagen ondecodeerbare of illegale zetbytes.
CompleteCTG blijft false: volledige ondersteuning van het CTG-formaat is niet bewezen.
RawFooter in de statistiekuitvoer bewaart de 33 bronbytes als base64. Wins/Losses/Draws en Recommendation volgen de oude decoderinterpretatie; dit zijn geen nieuw bewezen Fritz-gewichten. Ze staan niet in de neutrale PGN.

Beperkingen
Onderpromoties en bijzondere symmetrie van pionloze stellingen zijn niet volledig ondersteund/gevalideerd. De decoder veronderstelt bij herkenbare promoties een dame; PromotionAssumptions telt deze gevallen.
De doorloop dekt stelling-zetverbindingen, niet iedere mogelijke volgorde van transposities. Iedere stelling wordt op haar kortste bereikbare diepte verwerkt. Herhalingszetten blijven aanwezig, zonder eindeloos verder te lopen.
Perfect2023 is volledig op PGN-legaliteit gecontroleerd. De Windows-proef met Perfect2023 is geslaagd; alle 15.325 geëxporteerde records zijn zonder illegale zetten of leesfouten verwerkt. De boekweergave in Fritz is aanvullend onderzocht. Daarbij is geen verlies van 1...e5, 1...c6 of de Berlijnse route in de PGN vastgesteld.

Broncode
De volledige Source2Metal-bron staat in Source2Metal_v3.3.1_SOURCE.zip. Het validatierapport en de bron bevatten de reproduceerbare controles voor deze release.

CLI: --input PATH --mode all --workers 18 --ctg-max-ply 0 --no-pause
PGN-waarschuwing: onbruikbare uitslagen (*) blokkeren de verwerking niet; de volgende bron begint automatisch.

EN

Source2Metal v3.3.1

CTG METAL
All decoded reachable book moves are preserved through neutral RAW lines, with result *.
No frequency filter, recommendations, learned weights or artificial results are imported.
METAL/Metal.pgn automatically combines CTG lines and selected GAME records without personal headers.
Use CTG lines for book import; they are not win/loss learning signals.
See the CTG JSON report for coverage, depth cutoffs and decoder limitations.

Use
Extract the RELEASE package and place the EXE beside the input files. Start it, choose a language, then RAW or RAW + METAL. Workers default to half the logical CPUs, rounded up (36 -> 18), and can be changed. RAW defaults to 100 plies; separate CTG depth 0 means no preset limit. Results are written under !Source2Metal_Output/<timestamp>. Sources are read-only.

RAW keeps GAME and BOOK sources separate. RAW + METAL also creates METAL/Metal.pgn. PGN/CBH/2CBH/BIN processing and the SyzygyCheck menu remain available. BIN still produces RAW only. The separately supplied Perfect2023 PGN is ready for book import; program packages contain no external books.

Each CTG output includes a JSON report and JSONL statistics. Positions/Edges count unique positions/moves; ExportedEdges counts represented moves; DepthCutMoves counts moves beyond the limit. RawFooter contains 33 original bytes in base64. Other statistics retain the legacy interpretation, not verified Fritz learning weights. They never enter neutral PGN.

Limits
Underpromotion and pawnless symmetry are unverified; recognized promotions assume a queen. CompleteCTG remains false. Coverage concerns position/move pairs, not every transposition path. Each position is processed at its shortest reachable depth. Cycles are represented without infinite expansion.
Perfect2023 passed independent PGN legality validation. The Windows test with Perfect2023 completed successfully: all 15,325 exported records were processed without illegal moves or parse errors. The Fritz book display was also investigated; no loss of 1...e5, 1...c6 or the Berlin route was found in the PGN. Full source and reproducible checks are in the separate SOURCE ZIP.

CLI: --input PATH --mode all --workers 18 --ctg-max-ply 0 --no-pause
PGN warning: if many records have an unusable result (such as *), processing continues automatically; no keyboard input is needed.

CTG METAL
Все декодированные доступные ходы сохраняются в нейтральных линиях RAW с результатом *.
Без фильтра частоты, рекомендаций, обученных весов и вымышленных результатов.
METAL/Metal.pgn объединяет линии CTG и выбранные партии GAME без персональных заголовков.
Линии CTG предназначены для импорта книги, а не для обучения по победам и поражениям.
JSON-отчёт содержит покрытие, ограничения глубины и ограничения декодера.

Использование
Распакуйте пакет RELEASE, поместите EXE рядом с исходными файлами, запустите и выберите язык и RAW либо RAW + METAL. По умолчанию используется половина логических потоков с округлением вверх (36 -> 18); число настраивается. RAW: 100 полуходов. Отдельная глубина CTG 0 означает отсутствие заданного предела. Результаты: !Source2Metal_Output/<дата-время>. Источники доступны только для чтения.
RAW разделяет GAME и BOOK. RAW + METAL также создаёт METAL/Metal.pgn. Сохраняются PGN/CBH/2CBH/BIN и меню SyzygyCheck. BIN по-прежнему создаёт только RAW. Отдельная PGN Perfect2023 готова для импорта книги.
JSON-отчёт содержит число позиций, экспортированных ходов и отсечений глубины. Статистика хранится отдельно в JSONL. RawFooter сохраняет 33 исходных байта в base64. Остальные поля используют прежнюю интерпретацию; это не подтверждённые обученные веса Fritz.
Ограничения: слабые превращения и симметрия позиций без пешек не проверены; распознанное превращение считается превращением в ферзя. CompleteCTG остаётся false. Покрываются пары позиция/ход, а не все пути транспозиций. Циклы не разворачиваются бесконечно.
PGN Perfect2023 прошла независимую проверку легальности. Тест в Windows с Perfect2023 завершён успешно: все 15 325 экспортированных записей обработаны без незаконных ходов и ошибок чтения. Отображение книги во Fritz также исследовано; в PGN не обнаружена потеря 1...e5, 1...c6 или берлинского варианта. Полный исходный код и воспроизводимые проверки находятся в SOURCE ZIP.

Source2Metal v3.3.1

CTG METAL
保留所有可达且已解码的开局库着法，输出中性 RAW 变例，结果为 *。
不使用频率筛选、推荐、学习权重或虚构结果。
METAL/Metal.pgn 自动合并 CTG 变例及筛选后的 GAME 对局，并移除个人头信息。
CTG 变例用于导入开局库，不是胜负学习信号。
JSON 报告列出覆盖率、深度截断和解码器限制。

使用方法
解压 RELEASE 软件包，将 EXE 放在输入文件旁，启动后选择语言及 RAW 或 RAW + METAL。默认使用逻辑 CPU 数量的一半，向上取整（36 -> 18），可调整。RAW 默认深度为 100 半回合；单独的 CTG 深度为 0 时不预设上限。结果位于 !Source2Metal_Output/<时间戳>。源文件只读。
RAW 区分 GAME 和 BOOK；RAW + METAL 还会生成 METAL/Metal.pgn。保留 PGN/CBH/2CBH/BIN 处理及 SyzygyCheck 菜单。BIN 仍仅生成 RAW。单独提供的 Perfect2023 PGN 可直接用于开局库导入。
JSON 报告统计局面、已导出着法及深度截断。JSONL 单独保存统计信息；RawFooter 以 base64 保存 33 个原始字节。其他字段沿用旧版解释，并非已验证的 Fritz 学习权重。
限制：低升变和无兵局面对称尚未验证；可识别的升变按升后处理。CompleteCTG 保持 false。覆盖的是局面与着法的组合，不是全部转置路径；循环不会无限展开。
Perfect2023 已通过独立 PGN 合法性检查。Perfect2023 的 Windows 测试已成功完成：全部 15,325 条导出记录均无非法着法或读取错误。还检查了 Fritz 开局库显示；PGN 中未发现 1...e5、1...c6 或柏林防御路线丢失。完整源代码和可重复检查位于 SOURCE ZIP。

CLI: --input PATH --mode all --workers 18 --ctg-max-ply 0 --no-pause
PGN 提示：如果大量记录的结果不可用（例如 *），程序会自动继续处理，无需按键。
