Source2Metal v3.3.1

CTG METAL
Все декодированные доступные ходы сохраняются в нейтральных линиях RAW с результатом *.
Без фильтра частоты, рекомендаций, обученных весов и вымышленных результатов.
METAL/Metal.pgn объединяет линии CTG и выбранные партии GAME без персональных заголовков.
Линии CTG предназначены для импорта книги, а не для обучения по победам и поражениям.
JSON-отчёт содержит покрытие, ограничения глубины и ограничения декодера.

Использование
Распакуйте пакет RELEASE, поместите EXE рядом с исходными файлами, запустите и выберите язык и RAW либо RAW + METAL. По умолчанию используется половина логических потоков с округлением вверх (36 -> 18); число настраивается. RAW: 100 полуходов. Отдельная глубина CTG 0 означает отсутствие заданного предела. Результаты: !Source2Metal_Output/<дата-время>. Источники доступны только для чтения.
RAW разделяет GAME и BOOK. RAW + METAL также создаёт METAL/Metal.pgn. Сохраняются PGN/CBH/2CBH/BIN и меню SyzygyCheck. BIN по-прежнему создаёт только RAW. Отдельная PGN Perfect2023 готова для импорта книги.
JSON-отчёт содержит число позиций, экспортированных ходов и отсечений глубины. Статистика хранится отдельно в JSONL. RawFooter сохраняет 33 исходных байта в base64. Остальные поля используют прежнюю интерпретацию; это не подтверждённые обученные веса Fritz.
Ограничения: слабые превращения и симметрия позиций без пешек не проверены; распознанное превращение считается превращением в ферзя. CompleteCTG остаётся false. Покрываются пары позиция/ход, а не все пути транспозиций. Циклы не разворачиваются бесконечно.
PGN Perfect2023 прошла независимую проверку легальности. Тест в Windows с Perfect2023 завершён успешно: все 15 325 экспортированных записей обработаны без незаконных ходов и ошибок чтения. Отображение книги во Fritz также исследовано; в PGN не обнаружена потеря 1...e5, 1...c6 или берлинского варианта. Полный исходный код и воспроизводимые проверки находятся в SOURCE ZIP.

CLI: --input PATH --mode all --workers 18 --ctg-max-ply 0 --no-pause

Предупреждение PGN: если у многих записей недопустимый результат (например, *), обработка продолжается автоматически; ввод с клавиатуры не требуется.
