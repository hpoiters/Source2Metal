# Privacy policy

Source2Metal and SyzygyCheck are local Windows command-line utilities.

They do not collect telemetry, create user accounts, send chess data to a server, or transfer information to other networked systems during normal operation.

**This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.**

Source2Metal reads supported local chess-source files and writes its results to local output folders. SyzygyCheck checks local `.rtbw` and `.rtbz` Syzygy tablebase files in a folder selected by the user and, when requested, its real subfolders.

The project repository and release downloads are hosted by GitHub; use of GitHub itself is governed by GitHub's own privacy terms.
