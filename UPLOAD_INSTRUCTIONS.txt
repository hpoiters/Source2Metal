SOURCE2METAL GITHUB PUBLICATION NOTES v3.0.9
============================================

The v3.0.9 source tree is prepared for the public Source2Metal GitHub
repository. The Source2Metal processing logic remains unchanged from v3.0.7.

It contains:
- public source trees for Source2Metal v3.0.9 and SyzygyCheck v2.0.9 V9F;
- the exact v3.0.9 source archive used as the embedded-source build input;
- build/reproducibility documentation;
- privacy and third-party notices;
- code-signing policy preparation.

The v3.0.9 GitHub Actions workflow tests the source, builds the unsigned
Windows executable and publishes the complete release package and SHA-256 list.

The complete end-user distribution is a GitHub RELEASE asset and is not mixed
into the repository source tree.
